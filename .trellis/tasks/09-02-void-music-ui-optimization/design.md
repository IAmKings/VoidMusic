# Void Music UI 优化 — 设计

## 目标体验

主界面是“可演奏的取景器”，不是常驻的参数编辑页。用户打开应用后应立即看见相机、鼓区、模式和关键状态；需要调色时再展开完整 HSV 控件。沿用浅紫＋橙色的明亮创作工具基调，采用半透明中性表面确保文字压在真实相机画面上仍清晰。

## 布局层级

```
全屏 CameraPreview + 检测覆盖层
├── 顶部：紧凑 HUD（模式切换 + 关键状态）
├── 右侧：圆形快捷操作（校准、设置）
├── 底部：模式相关的紧凑控制坞
│   ├── TAP：当前颜色/鼓声 + “调参”入口
│   └── STEP：播放、BPM、清空
└── ModalBottomSheet：颜色预设、取色与 HSV 范围（仅按需展开）
```

## 组件边界

- `MainScreen` 保持相机、会话和检测/音频编排职责；以单一 `showColorControls` 状态控制 HSV sheet，默认关闭。
- `HudPanel` 收紧为模式切换与可横向滚动/压缩的状态信息，避免状态 chip 在窄屏挤压或截断。
- 新增 TAP 模式的轻量控制坞组件，只显示当前预设、映射鼓声和“调参”入口；不复制 HSV 编辑逻辑。
- `ColorControls` 作为可复用的完整高级编辑内容，放入 `ModalBottomSheet`；颜色预设继续使用 `LazyRow`，保留现有回调与持久化行为。
- `SequencerControls` 保留既有播放、BPM 和清空语义，只调整容器密度与视觉层级，使其与 TAP 控制坞一致。
- `SettingsRepository` 在现有 DataStore 内单独保存引导完成标记，不把它混入可“恢复默认”的演奏设置 JSON；`SessionViewModel` 暴露加载状态和完成操作，`MainActivity` 仅在读取完成后确定导航首屏。

## 引导导航规则

- 未完成引导：启动至引导页；点击“跳过”或“开始体验”后标记完成，并进入主界面。
- 已完成引导：冷启动直接进入主界面，不短暂闪现引导页。
- 设置页的“查看使用指南”可打开引导页；完成后清除设置页回退栈，回到主界面。
- “恢复默认设置”不更改引导完成标记，避免因重置演奏参数而再次强制引导。

## 视觉规则

- 保留橙色作为主操作色、浅紫作为选中/辅助表面色；鼓区原有红、蓝、绿、黄语义色不变。
- 相机上的 HUD 使用深色半透明 scrim 和高对比文字；参数 sheet 使用不透明或高不透明浅色表面，避免视频背景干扰滑杆读取。
- 操作图标必须含 `contentDescription`；仅用颜色传递的信息同时提供文字/图标。
- 避免 Extended FAB 的长文字占用实时画面，采用圆形图标按钮，并以短标签或可访问说明表达用途。

## 兼容性与风险

- 不更改 CameraPreview 尺寸、覆盖层坐标或输入事件优先级；HSV 取色开启时仍由现有全屏 tap catcher 接收点击。
- 打开 sheet 时仍可选择预设、启动取色和修改范围；取色后 sheet 自动保留或关闭的行为将以不会遮挡采样结果为准。
- 仅修改 Compose 呈现和状态，不修改 `SessionViewModel`、DataStore schema、DrumEngine 或 FrameRouter。
- 回退方式：恢复 `MainScreen` 的常驻 `ColorControls` 分支；不会影响已持久化的 HSV 数据。
