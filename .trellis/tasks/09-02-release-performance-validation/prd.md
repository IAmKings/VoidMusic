# 发布性能与真机验收

## Goal

以可复现的 release 构建和高、中、低三档实体设备测量，证明或否决根 PRD §12 的发布承诺。

## Requirements

- 在具备充足磁盘空间的环境构建可安装 release APK，并实测大小。
- 记录每台设备的型号、SoC、RAM、Android 版本、构建 SHA、性能档位和测试条件。
- 测量预览/分析 FPS、击打到出声延迟、Oboe 流延迟、冷启动、峰值内存、20 分钟稳定性及温升。
- 验证后台停止并释放相机、手部追踪和音频。
- 复核 Manifest/运行时代码无 INTERNET、无相机帧持久化/上传，且用户可见隐私说明和权限文案正确。
- 任何一档未通过均阻断正式发布，只能标记内部测试版。

## Acceptance Criteria

- [x] release APK 构建成功且 <80MB。
- [ ] 高端机 ≥60 FPS、<80ms；中端机 ≥30 FPS、<100ms；低端机降级可用、<150ms。
- [ ] Oboe 音频流 <40ms，冷启动 <3 秒，峰值内存 <400MB。
- [ ] 每台设备连续 20 分钟无崩溃、无明显卡顿，温升 ≤12°C。
- [x] 隐私与权限清单全部通过，并存有测试记录。

## Out of Scope

- CI 云真机服务、崩溃上报、网络性能监控。

## Dependencies

- 仅在前三个子任务均通过其功能门后启动最终验收。
