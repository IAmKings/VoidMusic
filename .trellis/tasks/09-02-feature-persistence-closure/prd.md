# 核心功能与持久化闭环

## Goal

补齐根 PRD 的 P0 与承诺纳入的 F7/F8 P1：取色、可感知力度、两套可切换 Kit、完整设置与会话恢复。

## Requirements

- 在取景器实现点击取色：读取当前帧 HSV，以可配置 buffer 生成范围，并即时更新活动预设。
- 消费视觉任务的真实 velocity 与稳定 Zone ID，保持击打反馈与显示一致。
- 提供至少两套声音可感知不同的内置 Kit；选择后实际传入音频引擎，而非只保存索引。
- 设置页包含性能档位、振动、主音量、Kit、灵敏度、防抖、平滑参数及恢复默认确认。
- DataStore 恢复模式、BPM、序列、校准、检测配置和所有设置；Room 管理内置 Kit 元数据并满足基础 CRUD。
- 设置变化异步且能实时传播到相机、检测和音频层。

## Acceptance Criteria

- [ ] 点击取色后目标区域被识别，HSV 设置重启后恢复。
- [ ] 两套 Kit 均实际切换并能听出差异。
- [ ] 所有设置控件可用、重启后恢复；重置需要确认且恢复默认。
- [ ] 模式、序列、校准和检测配置可恢复；数据库 CRUD 有测试。
- [ ] 关键持久化、取色和 Kit 接入拥有回归测试。

## Out of Scope

- P2 自定义导入、云备份和多套校准预设管理。

## Dependencies

- Kit 接入依赖 `native-audio-build` 的稳定音频 API；击打显示依赖 `vision-hit-correctness`。
