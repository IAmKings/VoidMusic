# M6: 性能优化与全机型测试

## Goal

延迟调优（端到端 <100ms）、发热优化、兼容性矩阵验证、包体积控制（OpenCV 精简），达到根 PRD 第 4 章全部非功能指标。

工期 1.5 周。

## Requirements

### R6.1 端到端延迟调优

| 指标 | 目标 | 来源 |
|------|------|------|
| 取景器渲染帧率 | ≥ 30 FPS（中端）/ ≥ 60 FPS（高端） | PRD §4.1 |
| 手部追踪推理帧率 | ≥ 25 FPS | PRD §4.1 |
| 击打→出声端到端延迟 | < 100 ms（P0），目标 < 80 ms（P1） | PRD §4.1 |
| 音频流延迟（Oboe） | < 40 ms | PRD §4.1 |
| 冷启动时间 | < 3 秒 | PRD §4.1 |

### R6.2 发热与电量

- 连续演奏 20 分钟，机身温升 ≤ 12°C（常温）。
- 进入后台立即停止摄像头与音频，释放资源。
- 提供性能档位（高 / 中 / 低），低端机降帧降分辨率。

### R6.3 兼容性矩阵验证

按 PRD §12.3 三档验证：

| 档位 | 代表设备 | 帧率 | 延迟 |
|------|---------|------|------|
| 高端 | 骁龙 8 Gen 系列 / 天玑 9300 | ≥ 60 FPS | < 80ms |
| 中端 | 骁龙 7/6 系 / 天玑 7000 | 30~60 FPS | < 100ms |
| 入门 | 骓龙 4 系 / 4GB RAM | 降级可用 | < 150ms |

### R6.4 包体积控制

- 总体 APK < 80 MB（含 OpenCV 最小模块）。
- OpenCV 按需裁剪，仅保留 `imgproc`、`core` 等必要模块。
- 自研 HSV+连通域纯 Kotlin 实现作为备选裁剪路径。

### R6.5 内存与稳定性

- 峰值内存 < 400 MB（Android Profiler 验证）。
- 20 分钟连续运行无崩溃、无明显卡顿。
- 处理各厂商音频 HAL 差异（Oboe 低延迟 / 兼容双模式）。

### R6.6 隐私合规验收

- App 不申请 `INTERNET` 权限。
- 摄像头画面不写入磁盘、不上传。
- 隐私政策页明示纯本地处理。
- 权限申请有明确用途说明。

## Acceptance Criteria

- [ ] 高端机取景器帧率 ≥ 60 FPS、中端机 ≥ 30 FPS
- [ ] 击打→出声端到端延迟 < 100ms（高速摄像+波形对齐测量）
- [ ] Oboe 音频流延迟 < 40ms
- [ ] 冷启动 < 3 秒
- [ ] 20 分钟连续运行温升 ≤ 12°C
- [ ] 峰值内存 < 400 MB
- [ ] 高/中/低三档机型均通过兼容性矩阵
- [ ] APK 体积 < 80 MB
- [ ] 隐私合规验收全部通过（§12.4）
- [ ] 性能档位切换生效（高/中/低）

## Out of Scope

- 网络相关功能（首版无 INTERNET 权限）
- 云端性能监控 / 崩溃上报
- 自动化 CI 性能回归测试

## Priority

| Priority | Requirements | Rationale |
|----------|-------------|-----------|
| **P0** | R6.1 (延迟+音频), R6.4 (包体积) | Audio no-op blocks usability; 156MB APK is 2x target |
| **P1** | R6.2 (发热), R6.3 (兼容矩阵), R6.5 (内存), R6.6 (隐私) | Important but not blocking basic functionality |

## Dependencies

- M0-M5 全部完成并通过各自验收 — M6 是最后的性能打磨与兼容验证阶段
- NDK 环境安装是 R6.1 音频系统的前置条件
